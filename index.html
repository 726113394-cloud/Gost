游戏流程

  1. 准备阶段 — 玩家进入匹配队列，满员后开始游戏
  2. 感染阶段 — 鬼玩家追逐并感染人类，人类可拾取道具自保
  3. 神圣守护阶段 — 剩余人类数量 ≤ 触发人数时，自动激活神圣守护
  4. 猎魔人阶段 — 游戏剩余 90 秒时进入，拥有神圣守护的人类变为猎魔人反杀鬼

⚔️ 猎魔人阶段 v2.2.2 ~ v2.3.0

  • 所有拥有神圣守护的人类变为 猎魔人
  • 猎魔人持有 收割者 道具，基于伤害值击杀鬼玩家（可配置）
  • 普通鬼 不能感染人类，只能躲避猎杀
  • 母体 可以攻击猎魔人，每次造成配置的伤害值
  • 母体需要攻击 3 次 才能破除猎魔人的神圣守护
  • 所有 神之救赎 道具被清除
  • 鬼玩家血量调整（普通鬼 2❤，母体鬼 3❤）
  • 猎魔人阶段 禁止回血（自然恢复、饱食度、药水均无效）
  • 鬼被击杀后进入死亡状态（默认隐身，可在 config 切换为旁观），可配置复活时间

⚔️ 猎魔人阶段 v2.3.3 当前

🗡️ 收割者（伤害值判定）

  • 左键单体攻击：按配置伤害扣血，显示 伤害量 + 剩余血量，血量归零进入旁观 + 复活倒计时
  • 右键范围技能「收割」：以自身为中心 4 格 AOE，伤害与左键一致，冲击粒子 + 凋零死亡音效，冷却 10 秒
  • 左键攻击冷却 2 秒

👻 鬼死亡 → 死亡状态 → 复活（v2.4.0 死亡状态可配）

  • 死亡进入可配置的死亡状态：death-state.mode = invisible（默认，隐身）或 spectator（旁观）
  • 复活倒计时（ActionBar 显示）
  • 倒计时结束在游戏区域内 随机坐标 换回 生存模式 复活
  • 复活后恢复原身份（普通鬼/母体）继续参与对局
  • 击杀位置绽放 红黄 BURST 烟花 + 爆炸粒子 + 凋零死亡音效

🎯 猎魔人被母体击杀（v2.3.3）

  • 被母体击杀后立刻转为 普通鬼（死亡状态）
  • 旁观 + 复活倒计时结束后以 普通鬼 身份继续对局

👑 母体进化水晶（v2.3.3 阶段调整）

  • 出现阶段：神圣守护阶段（原先猎魔人阶段）
  • 生成：固定坐标 / 区域中心 / 区域随机（可配置），放置 发光绿宝石
  • 拾取条件：仅普通鬼可拾取
  • 效果：拾取后变身为母体鬼

🛡️ 猎魔人阶段防御规则

  • 阵营伤害保护：猎魔人无法伤害人类/猎魔人，鬼无法伤害鬼，人类无法伤害人类
  • 死亡拦截：鬼/猎魔人真实死亡事件被取消
  • 环境伤害免疫：鬼/猎魔人免疫坠落/岩浆/火焰等
  • 正常回血：玩家可正常恢复

👑 母体攻击猎魔人

  • 无神圣守护猎魔人：母体 4 次 击中 → 转为普通鬼（旁观复活）
  • 有神圣守护猎魔人：先 3 次 破除守护，再 4 次 击杀

🚫 母体禁足

  • 对局开始前母体随机锁定游戏区域坐标，20 秒 无法移动
🧰 道具系统
📖 查看道具说明

道具会在游戏过程中 定时发放 给玩家，每次发放间隔可在配置中调整（默认每 60 秒发放一次），同时区域会随机刷新道具。发放道具时会揭示所有玩家位置 5 秒。

背包管理（v2.3.1）：对局期间最多 9 个 道具，不可放入背包，不堆叠，不允许相同道具（除通用道具外），收割者/神之救赎强制放第一格。

🗡️ 冲刺矛（v2.3.3 更新）：
• 右键使用进行冲刺，向前冲刺 5.5 米，使用后即刻消失。
• 全版本兼容：在 <1.21.4 版本中显示为 三叉戟，≥1.21.4 版本中显示为 矛，功能完全一致。
• 使用音效：凋零死亡音效。

🍖 饥饿值系统
📖 展开查看详情

v2.3.2 新增 — 对局饥饿值消耗功能，可配置、可开关。对局内饥饿值与局外独立，结算后恢复开局前饱食度。

⚙️ 核心机制

  • 进入对局时所有玩家饱食度 回满
  • 游戏过程中 奔跑 会正常消耗饱食度
  • 对局内的饥饿值 独立于局外，结算后恢复开局前状态
  • 此功能支持 开关 和 恢复速度 配置

👤 人类蹲下恢复

  • 按下 [Shift] 蹲下，每秒恢复 1 饱食度

👻 鬼蹲下恢复

  • 按下 [Shift] 蹲下，每 0.8 秒恢复 1 饱食度

🔄 阵容转换

  • 转换阵容时饱食度 回满

⚔️ 猎魔人阶段

  • 进入猎魔人阶段时饱食度 回满 且 不再消耗

配置项位于 config.yml 的 food 节点下，支持开关、恢复速度等参数调整。

👻 鬼转人类功能

游戏剩余 3 分钟 时，系统会随机将部分 非母体鬼玩家 转换回人类阵容（默认关闭，可在配置中启用）。

🏆 经济与奖励系统

入场与奖池

玩家加入游戏需支付 入场费（默认 100 金币），入场费汇入 人类奖池；服务器可设置 额外奖金（默认 5000 金币），增加奖池总额。

胜利奖金分配

胜利方分配规则
👤 人类胜利人类阵容获得奖池 70%，鬼阵容获得 30%
👻 鬼胜利鬼阵容获得奖池 100%

个人奖金计算

阵营分配方式
👤 人类100% 按 存活时间比例 分配
👻 鬼70% 按 鬼存活时间 + 30% 按 感染人数比例 分配

猎魔人奖励

猎魔人每击杀一名鬼玩家，可获得 人类奖池 30% 的奖金；母体 击杀猎魔人可获得 50% 的额外奖励（高于普通感染奖励）。

奖金排行榜

游戏结束后显示奖金排行榜，前三名显示 🥇🥈🥉 奖牌。

✨ 特色系统
📖 展开查看详情

🌑 黑暗效果与疾跑并存

使用 Minecraft 原生 DARKNESS 效果（1.19+）或 BLINDNESS 效果（旧版本）。
通过属性修改器增加 30% 移动速度，抵消黑暗效果对疾跑的影响。
每 10 ticks 检查玩家疾跑状态，自动恢复被阻止的疾跑。
管理员和创造模式玩家也会受到黑暗效果影响。

👻 鬼玩家粒子效果

鬼玩家身上持续显示环绕粒子效果。
母体鬼：红色粒子，普通鬼：绿色粒子。
支持 21 种粒子类型，RGB 颜色自定义。
可配置准备阶段是否显示。

💬 多语言系统（v2.3.3 六国语言文件）

支持 中文 / English / 日本語 / Español / Français / Deutsch。
语言文件：plugins/Gost/lang/<locale>.yml，用户可自行修改。
选择语言：config.yml → language.default 或 /gostadmin lang。
修改后 /gost reload 生效；智能回退与错误隔离。

❤️ 心跳声系统

游戏过程中人类方循环播放监守者出现时的心跳声。
管理员可通过 /gostadmin heartbeat 控制开关。

🎒 背包管理系统（v2.3.1）

对局期间最多 9 个 道具。
道具不可放入背包（强制移回物品栏）。
道具不堆叠、不允许两个相同道具、不允许两个肾上腺素（人鬼通用道具除外）。
收割者 / 神之救赎 强制放第一格。

🔥 选区粒子框（v2.3.1）

设置选区后自动显示 火焰粒子框，持续 30 秒。
帮助管理员直观确认游戏区域边界。

🌐 双语字幕（v2.3.1）

复活等待、重生、收割、救赎、母体禁足等核心事件新增 中英双语字幕。
根据服务器语言设置自动切换。

📦 版本与服务端兼容

支持 1.20.x 至 1.21.x。
Bukkit / Spigot / Paper / Purpur 等 Bukkit 系服务端完整支持；Folia 调度兼容。
Sponge 与代理端（BungeeCord/Velocity/Waterfall）不适用。
粒子/音效/属性/附魔跨版本自动兼容（ApiCompat / ParticleCompat / SoundCompat）。
